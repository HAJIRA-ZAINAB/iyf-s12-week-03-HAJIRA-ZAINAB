## What I Learned
- I learned the complete Git workflow: cloning a repo, creating branches like feat/responsive-nav and fix/accessibility-color-contrast, making meaningful commits, pushing to origin, and merging to main.
- I learned how to write professional commit messages using conventions like feat:, fix:, docs: and chore:.
- I learned how to deploy my portfolio using GitHub Pages and how to fix the 404 error when the live link takes time to go live.
- I learned to build a responsive, accessible portfolio with HTML5 and CSS3 Flexbox/Grid without using the file explorer, only using the command line in Git Bash and VS Code terminal.
- I learned the importance of a professional README and why we must replace all template placeholders with real personal info.

  ## Challenges Faced
- My main challenge was building the whole project without using file explorer, only using the command line.
- I faced issues with Git Bash commands showing errors and GitHub Pages not deploying instantly.
- I solved them by double-checking commands in VS Code terminal, using git status after every step, and waiting for Pages to deploy.
