## Project Description

- Responsive portfolio layout

- Clean and professional Git commit history
- Deployed live using Github pages

## Lessons learned
- While building this project I learned how to use terminal commands like pwd, 1s, cd, mkdir, touch to manage files.
- I learned the full git workflow from git init to push, how to write meaningful commit messages, and how to deploy using github.
- I also learned the importance of professional README.

## Challenges Faced
- The main challenge was building the whole project without using the file explorer, only using command line.
- I also faced issues with Github pages taking time to go live and with writing correct Git commands.
- I solved them by re-checking commands in Git Bash.
